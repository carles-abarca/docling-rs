Installation

docling-rs can be installed as a standalone CLI application or integrated as a library in your Rust projects. Choose the installation method that best fits your needs.

Pre-built Binaries

The easiest way to install docling-rs is using the pre-built binaries available for Windows, macOS, and Linux.

Windows

Download and run the MSI installer:

PowerShell
# Download the installer
Invoke-WebRequest -Uri "https://github.com/docling-rs/docling-rs/releases/latest/download/docling-rs-x86_64-windows.msi" -OutFile "docling-rs.msi"

# Run the installer
Start-Process msiexec.exe -ArgumentList "/i docling-rs.msi" -Wait

Or use the ZIP package:

PowerShell
# Extract to a directory in your PATH
Expand-Archive docling-rs-x86_64-windows.zip -DestinationPath "C:\Program Files\docling-rs"

macOS

Download and mount the DMG installer:

Terminal
# For Apple Silicon (M1/M2/M3)
curl -LO https://github.com/docling-rs/docling-rs/releases/latest/download/docling-rs-aarch64-macos.dmg
open docling-rs-aarch64-macos.dmg

# For Intel Macs
curl -LO https://github.com/docling-rs/docling-rs/releases/latest/download/docling-rs-x86_64-macos.dmg
open docling-rs-x86_64-macos.dmg

Or use Homebrew (coming soon):

Terminal
brew install docling-rs

Linux

Terminal
# Download and extract
curl -LO https://github.com/docling-rs/docling-rs/releases/latest/download/docling-rs-x86_64-linux.tar.gz
tar -xzf docling-rs-x86_64-linux.tar.gz

# Move to a directory in your PATH
sudo mv docling-rs /usr/local/bin/
sudo mv libpdfium.so /usr/local/lib/
sudo ldconfig

Rust Library

Add docling-rs to your Cargo.toml:

Cargo.toml
[dependencies]
docling-rs = "0.1"

Feature Flags

docling-rs uses feature flags to enable format backends. By default, only common formats are enabled. Use the full feature for all formats:

Cargo.toml
[dependencies]
docling-rs = { version = "0.1", features = ["full"] }

Available features:

Feature Description Default
markdown Markdown file support Yes
html HTML file support Yes
csv CSV file support Yes
docx Microsoft Word support Yes
xlsx Microsoft Excel support Yes
pptx Microsoft PowerPoint support Yes
pdf PDF file support (requires PDFium) No
full Enable all format backends No

PDF Support Setup

PDF processing requires the PDFium library. The pre-built installers include PDFium automatically. For development or custom builds:

Download PDFium

Terminal
# Create pdfium directory
mkdir -p pdfium/lib

# Download for your platform (example for macOS ARM64)
curl -LO https://github.com/nicklockwood/pdfium-lib/releases/download/v123/pdfium-macos-arm64.zip
unzip pdfium-macos-arm64.zip -d pdfium/lib/macos-arm64

Set Library Path

Terminal (macOS/Linux)
# macOS
export DYLD_LIBRARY_PATH="/path/to/pdfium/lib/macos-arm64:$DYLD_LIBRARY_PATH"

# Linux
export LD_LIBRARY_PATH="/path/to/pdfium/lib/linux-x64:$LD_LIBRARY_PATH"
PowerShell (Windows)
$env:PATH = "C:\path\to\pdfium\lib\windows-x64;$env:PATH"

Building from Source

To build docling-rs from source, you need Rust 1.75 or later:

Terminal
# Clone the repository
git clone https://github.com/docling-rs/docling-rs.git
cd docling-rs

# Build the CLI (release mode)
cargo build --release -p docling-rs-cli

# The binary will be at target/release/docling-rs

Verify Installation

After installation, verify everything works:

Terminal
# Check version
docling-rs --version

# Show help
docling-rs --help

# Test conversion
echo "# Test Document" > test.md
docling-rs test.md --to json
