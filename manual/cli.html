CLI Usage Guide

The docling-rs command-line interface provides powerful document conversion and processing capabilities for shell scripts, automation, and batch processing.

Basic Syntax

Terminal
docling-rs [OPTIONS] <INPUT>

Where <INPUT> is a file path or directory.

Command Options

Input/Output Options

Option Description Default
<INPUT> Input file or directory path (required) -
--output-dir <DIR> Output directory for converted files Current directory
--to <FORMAT> Output format: json, markdown, text markdown
--from <FORMATS> Filter input formats (comma-separated) All supported

Chunking Options

Option Description Default
--chunk Enable document chunking Disabled
--chunk-strategy <STRAT> Chunking strategy: hierarchical or hybrid hierarchical
--chunk-max-tokens <N> Maximum tokens per chunk (hybrid strategy) 512
--chunk-merge-peers Merge undersized peer chunks (hybrid strategy) true
Chunking Strategies

Hierarchical: Preserves document structure, creating chunks based on document elements (paragraphs, headings, lists). Best for maintaining context.

Hybrid: Token-aware chunking that respects token limits. Automatically splits oversized chunks and merges undersized ones. Ideal for embedding models with token limits.

Processing Options

Option Description
--continue-on-error Continue processing if a file fails (batch mode)
--abort-on-error Stop processing on first error (batch mode)
--verbose Show detailed processing information
--quiet Suppress all output except errors

PDF Options

Option Description
--pdf-extract-tables Extract tables from PDFs (requires table detection)
--pdf-extract-images Extract images from PDFs
--ocr-enabled Enable OCR for scanned documents

General Options

Option Description
-h, --help Show help message
-V, --version Show version information

Usage Examples

Single File Conversion

Terminal
# Convert PDF to Markdown
docling-rs report.pdf --to markdown --output-dir ./output

# Convert Word document to JSON
docling-rs document.docx --to json --output-dir ./output

# Convert Excel to plain text (output to stdout)
docling-rs data.xlsx --to text

Directory Processing

Terminal
# Convert all documents in a directory
docling-rs ./documents/ --to json --output-dir ./converted

# Convert only PDF and DOCX files
docling-rs ./documents/ --from pdf,docx --to markdown

# Process with verbose output
docling-rs ./documents/ --to json --verbose

Error Handling in Batch Mode

Terminal
# Continue even if some files fail
docling-rs ./documents/ --continue-on-error --to json

# Stop on first error
docling-rs ./documents/ --abort-on-error --to markdown

Chunking for RAG

Terminal
# Hierarchical chunking (default) - preserves document structure
docling-rs document.pdf --chunk --to json

# Hybrid chunking - token-aware, ideal for embeddings
docling-rs document.pdf --chunk --chunk-strategy hybrid --to json

# Hybrid with custom token limit
docling-rs document.pdf --chunk --chunk-strategy hybrid --chunk-max-tokens 256 --to json

# Hybrid without merging small chunks
docling-rs document.pdf --chunk --chunk-strategy hybrid --chunk-merge-peers false --to json

Output Structure

Single File Output

When converting a single file, the output file is named after the input:

Terminal
docling-rs report.pdf --to markdown --output-dir ./output
# Creates: ./output/report.md

docling-rs report.pdf --to json --output-dir ./output
# Creates: ./output/report.json

Directory Output

When converting a directory, the output structure mirrors the input:

Terminal
# Input structure:
documents/
  ├── report.pdf
  ├── data.xlsx
  └── subdir/
      └── notes.md

# Command:
docling-rs ./documents/ --to json --output-dir ./output

# Output structure:
output/
  ├── report.json
  ├── data.json
  └── subdir/
      └── notes.json

Exit Codes

Code Meaning
0 Success - all files processed
1 Error - one or more files failed

Shell Integration

Bash Script Example

bash
#!/bin/bash

# Convert all PDFs in a directory
for pdf in ./documents/*.pdf; do
    if docling-rs "$pdf" --to json --output-dir ./output; then
        echo "Converted: $pdf"
    else
        echo "Failed: $pdf" >&2
    fi
done

PowerShell Example

PowerShell
# Convert all documents and log results
Get-ChildItem -Path .\documents -Recurse -Include *.pdf,*.docx | ForEach-Object {
    $result = docling-rs $_.FullName --to json --output-dir .\output 2>&1
    if ($LASTEXITCODE -eq 0) {
        Write-Host "Success: $($_.Name)" -ForegroundColor Green
    } else {
        Write-Host "Failed: $($_.Name)" -ForegroundColor Red
    }
}

Unix Pipes

Terminal
# Find and convert all PDFs
find ./documents -name "*.pdf" -exec docling-rs {} --to markdown --output-dir ./output \;

# Convert and pipe to another tool
docling-rs document.pdf --to text | wc -w
# Outputs word count

# Convert and search content
docling-rs document.pdf --to text | grep -i "keyword"
Note on Conflicting Options

The following option pairs cannot be used together:

  • --verbose and --quiet
  • --continue-on-error and --abort-on-error
