docling-rs Developer Manual

docling-rs is a high-performance document processing library written in Rust. It provides unified document conversion, text extraction, and intelligent chunking capabilities for building RAG (Retrieval-Augmented Generation) applications.

What is docling-rs?

docling-rs converts documents from various formats (PDF, DOCX, XLSX, PPTX, HTML, Markdown, CSV) into a unified document model that can be exported to JSON, Markdown, or plain text.

Key Features

  • ✓ Multi-format support - PDF, DOCX, XLSX, PPTX, HTML, Markdown, CSV
  • ✓ Unified document model - Consistent output regardless of input format
  • ✓ Intelligent chunking - Hierarchical and hybrid chunking strategies for RAG
  • ✓ High performance - Native Rust implementation with parallel processing
  • ✓ Cross-platform - Windows, macOS, and Linux support
  • ✓ CLI and Library - Use as a command-line tool or integrate as a library

Example Usage

Command Line

Terminal
# Convert a PDF to Markdown
docling-rs document.pdf --to markdown --output-dir ./output

# Convert with chunking for RAG
docling-rs document.pdf --to json --chunk --chunk-size 512

# Batch convert a directory
docling-rs ./documents/ --to json --output-dir ./converted

Rust Library

Rust
use docling_rs::{DocumentConverter, InputFormat};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Create a converter
    let converter = DocumentConverter::new();

    // Convert a file
    let result = converter.convert_file("document.pdf")?;

    // Access the document
    let doc = result.document();
    println!("Document: {}", doc.name());
    println!("Nodes: {}", doc.nodes().len());

    // Export to Markdown
    let markdown = doc.to_markdown();
    println!("{}", markdown);

    Ok(())
}
