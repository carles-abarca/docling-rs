API Reference

Complete reference for the docling-rs Rust library API. For full documentation with all types and methods, see the generated Rust docs at docs.rs/docling-rs.

Core Types

DocumentConverter

The main entry point for document conversion.

pub struct DocumentConverter
A high-level converter that automatically detects input formats and uses the appropriate backend for conversion.
impl DocumentConverter {
  pub fn new() -> Self
Creates a new DocumentConverter with all enabled format backends.
  pub fn convert_file<P: AsRef<Path>>(
    &self,
    path: P
  ) -> Result<ConversionResult, ConversionError>
Converts a document from a file path. The format is automatically detected from the file extension.
  pub fn convert_bytes(
    &self,
    bytes: Vec<u8>,
    name: String,
    format: InputFormat
  ) -> Result<ConversionResult, ConversionError>
Converts a document from raw bytes with an explicit format specification.

DoclingDocument

The unified document model representing a converted document.

pub struct DoclingDocument
Represents a parsed document with a hierarchical structure of nodes. Contains the document name, source information, and content nodes.
impl DoclingDocument {
  pub fn name(&self) -> &str
Returns the document name (usually the original filename).
  pub fn nodes(&self) -> &[DocumentNode]
Returns a slice of all document nodes in order.
  pub fn to_markdown(&self) -> String
Exports the document to Markdown format.
  pub fn to_text(&self) -> String
Exports the document to plain text format.

DocumentNode

Represents a single element in the document structure.

pub struct DocumentNode
A node in the document tree containing content item and optional metadata.
impl DocumentNode {
  pub fn item(&self) -> &NodeItem
Returns the content item for this node.

Supported input document formats.

pub enum InputFormat {

  Docx,
  Xlsx,
  Pptx,
  PDF,
}
Enumeration of supported input formats.
impl InputFormat {
  pub fn from_extension(ext: &str) -> Option<Self>
Detects the format from a file extension string.
  pub fn from_bytes(bytes: &[u8]) -> Option<Self>
Detects the format from file magic bytes.
