Supported Formats

docling-rs supports a wide range of document formats for input, with multiple output options for different use cases.

Input Formats

Format Extensions Feature Flag Description
Markdown .md, .markdown markdown CommonMark and GitHub Flavored Markdown
HTML .html, .htm html HTML documents with semantic extraction
CSV .csv csv Comma-separated values (tabular data)
Word .docx, .dotx, .docm, .dotm docx Microsoft Word documents (Office Open XML)
Excel .xlsx, .xlsm, .xlsb, .xls xlsx Microsoft Excel spreadsheets
PowerPoint .pptx, .potx, .ppsx, .pptm pptx Microsoft PowerPoint presentations
PDF .pdf pdf PDF documents (requires PDFium library)

Output Formats

Format CLI Option Description
JSON --to json Full document model with metadata, ideal for programmatic processing
Markdown --to markdown Human-readable format preserving document structure
Text --to text Plain text extraction, ideal for search and analysis

Format Details

Markdown

The Markdown backend parses CommonMark and GitHub Flavored Markdown (GFM). It extracts:

  • Headings (H1-H6) with hierarchy preservation
  • Paragraphs with inline formatting
  • Lists (ordered and unordered)
  • Code blocks with language detection
  • Tables (GFM syntax)
  • Links and images
  • Blockquotes

HTML

The HTML backend uses semantic parsing to extract meaningful content:

  • Headings (<h1>-<h6>)
  • Paragraphs and text content
  • Lists (<ul>, <ol>)
  • Tables with header detection
  • Links and images
  • Handles malformed HTML gracefully
Note

Script and style content is automatically stripped. Only semantic content is extracted.

CSV

CSV files are processed as tabular data:

  • First row treated as headers
  • Each row becomes a TableRow node
  • Supports various delimiters (auto-detected)
  • Handles quoted fields with commas

Microsoft Word (DOCX)

Word documents are processed using Office Open XML parsing:

  • Headings with style-based level detection
  • Paragraphs with formatting
  • Lists (numbered and bulleted)
  • Tables with merged cells support
  • Embedded images (metadata only)

Microsoft Excel (XLSX)

Excel spreadsheets are converted with sheet-level organization:

  • Each sheet becomes a section
  • Cell data extracted as tabular content
  • Formula results (not formulas) are extracted
  • Supports multiple sheets

Microsoft PowerPoint (PPTX)

Presentations are converted slide-by-slide:

  • Each slide becomes a section
  • Title and content extraction
  • Bullet points preserved
  • Speaker notes (if present)

PDF

PDF processing uses the PDFium library for high-quality extraction:

  • Text extraction with reading order detection
  • Page-by-page processing
  • Paragraph detection
  • Multi-column layout support
PDF Requirements

PDF support requires the PDFium library to be installed. See Installation Guide for setup instructions.

Feature Combinations

Cargo.toml
# Enable only specific formats
[dependencies]
docling-rs = { version = "0.1", default-features = false, features = ["markdown", "html"] }

# Enable all formats
[dependencies]
docling-rs = { version = "0.1", features = ["full"] }

# Default features (no PDF)
[dependencies]
docling-rs = "0.1"

Format Detection

docling-rs automatically detects input formats using:

  1. File extension - Primary detection method
  2. Magic bytes - Fallback for ambiguous extensions
Rust
use docling_rs::InputFormat;

// Detect from extension
let format = InputFormat::from_extension("pdf");
assert_eq!(format, Some(InputFormat::PDF));

// Detect from bytes
let pdf_bytes = std::fs::read("document.pdf")?;
let format = InputFormat::from_bytes(&pdf_bytes);
assert_eq!(format, Some(InputFormat::PDF));
